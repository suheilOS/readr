# Overhawl Launch Doc

I have decided to build Overhawl, a set of software products that borrow from the functional simplicity of pen and paper.

I hate how software gets more complicated to use over time. Nowadays, I find myself buried deep in menus and settings, which only add to the cognitive load. Managing them becomes rewarding in itself instead of actually engaging in meaningful work.

While I would have preferred to rely solely on pen and paper, it isn’t easily indexed. You have to manually go through and skim all the pages to find what you’re looking for. It just so happens that computers are exceptional at indexing. I also primarily use my laptop for most of my work and studies.

So with this in mind, I started by thinking:

> **“What is the minimum an interface needs without sacrificing functionality? How much can I reduce the number of decisions a user has to make before taking the first step?”**

It has been such an interesting experience trying to prototype and refine the first two products. While I am building them primarily for myself, I do hope that some of you are facing the same challenges and that my technical decisions resonate with the way some of you want software to work.

**None of them will have any subscriptions or one-time purchases.** I see no reason to charge for any of the products I build during this journey. That would defeat the purpose of building them in the first place.
